🔁 Syncing this file with Notion
1On the Data tab in this app, click Export JSON. This downloads all your entries.
2In Notion, open your Pilgrimage Log database and click ··· → Import → CSV. You can convert the JSON to CSV using a free tool like csvjson.com.
3For an automated sync, create a free Zapier or Make workflow: trigger on a daily schedule, read your JSON export, and create/update a Notion row for today's entry.
4If you are comfortable with code, use the Notion API (free) with a simple script — the Data tab shows you exactly what fields to send.

Recommended views in Notion:
  • Calendar view filtered to current month
  • Gallery view grouped by Season
  • Table view grouped by Energy level
  • Board view of Quests grouped by Status
